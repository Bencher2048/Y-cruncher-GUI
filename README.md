## О проекте

За основу взяты:

- **y-cruncher 0.8.7** – https://github.com/Mysticial/y-cruncher репозиторий оригинального y-cruncher
- HWinfo64 для вывода датчиков
  
Все исходники проекта доступны в репозитории.

Если вы не доверяете готовым `.exe`-файлам, можетее самостоятельно собрать программу из исходного кода.
